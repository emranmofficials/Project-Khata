# Project Khata (প্রজেক্ট খাতা)

ঠিকাদারি ও নির্মাণ কাজের জন্য একটি প্রতিষ্ঠান-ভিত্তিক মোবাইল অ্যাপ। প্রজেক্ট, শ্রমিকের হাজিরা, সুপারভাইজারের দৈনিক এন্ট্রি, সাইট লোকেশন যাচাই, মালামাল ও মজুরির হিসাব একটি জায়গায় পরিচালনা করে।

## প্রযুক্তি

- **ফ্রন্টএন্ড:** Flutter (Android ও iOS)
- **ব্যাকএন্ড:** Supabase (PostgreSQL, Auth, RLS, Storage, Realtime, Edge Functions)
- **নোটিফিকেশন:** Firebase Cloud Messaging (FCM)
- **ম্যাপ:** Google Maps SDK ও Places API

## ইউজার রোল

| রোল | ভূমিকা |
|---|---|
| ঠিকাদার | প্রতিষ্ঠানের মালিক; প্রজেক্ট, ইউজার, পদ, মজুরি ও পেমেন্ট নিয়ন্ত্রণ |
| ক্লায়েন্ট | প্রজেক্টের অগ্রগতি, মালামাল ও শ্রমিক-বিল খতিয়ান দেখে |
| সুপারভাইজার | অ্যাসাইন করা প্রজেক্টে দৈনিক এন্ট্রি ও শ্রমিকের হাজিরা দেয় |
| শ্রমিক | নিজের হাজিরা, কাজ ও মজুরির হিসাব দেখে |

## বিল্ড ও চালানো

> Flutter প্রজেক্ট তৈরির পর এই অংশ হালনাগাদ হবে।

```bash
flutter pub get
flutter run
```

Android ও iOS বিল্ড GitHub Actions-এ হবে (`.github/workflows/`)।

## সেটআপ (Supabase)

1. Supabase প্রজেক্ট তৈরি করুন।
2. `.env.example` কপি করে `.env` বানান এবং `SUPABASE_URL` ও `SUPABASE_ANON_KEY` বসান।
3. Service-role key কখনও অ্যাপে বা রিপোজিটরিতে রাখবেন না। এটি শুধু Edge Functions-এর পরিবেশ-ভেরিয়েবলে থাকবে।
